## 🎯 Quick Reference

### To Use This Project:

**1. Clone it:**
```powershell
git clone https://github.com/balasureshk1984/rira.git
cd rira
npm install
npm run dev
```

**2. Open browser:**
```
http://localhost:5173
```

**3. Start learning!**
- Begin with Beginner level
- Follow all 15 modules
- Build robots!
